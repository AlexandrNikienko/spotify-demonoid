# <img src="https://spotify-demonoid.netlify.app/spotify-demonoid.png" alt="Spotify Demonoid logo" width="40" style="vertical-align: bottom;"> Spotify Demonoid

**It's a small experimental web app that transforms Spotify playlists into demo previews.**

It automatically plays short snippets of each track — perfect for artists, curators, or label owners who want to quickly preview or describe a playlist.
<br/><br/>
🚀 Features:

- 🔄 Auto-skip playback — plays a few seconds of each track, then moves to the next

- 🎚️ Randomized start positions — each track starts from a random time for variety

- 🎧 Spotify authorization flow (implicit grant)

<!--🧠 Smart playback modes:

nextWithSeek — skips to next track, then seeks to random time

🧩 Tech Stack

- Frontend: Vanilla JS / HTML / CSS

- API: Spotify Web API

- Playback: Spotify Web Playback SDK

- Hosting: Netlify

⚙️ How It Works

- User authorizes with Spotify

- Select and load a playlist

- Automatically plays a previews of each track (demo mode)

- Loops through the entire playlist
